📋 Instructions

  • Data CSV Format: Two columns named 'x' and 'y' with your data points
  • Parameters CSV Format: Two columns named 'a' and 'b' with parameter values for each iteration
  • Play: Animate through all parameter iterations automatically
  • Pause: Stop the animation at the current iteration
  • Step: Move forward one iteration at a time
  • Reset: Return to the first iteration
  • The sigmoid curve is calculated as: y = 1 / (1 + e^-(ax+b))
